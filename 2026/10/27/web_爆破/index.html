web23

打开靶场看见一段php代码

本来想复制过来审计的，但是一直调整不好格式，遂截图。

以下是代码是审计部分(orz太久不审计了需要复建一下，顺便记录一些函数功能)

  1. 设置读取token为get参数，将其md5化
  2. substr($token, 1, 1) 是 PHP 的字符串截取函数调用，作用是：从 $token 字符串的第 2 个字符开始，截取 1 个字符。
  3. 即，第一层条件校验为token的第2、15、18位字符相等
  4. intval() 是 PHP 的内置函数，作用是：获取一个变量的整数值。通常是直接截断，解析数字
  5. 即，第二层条件校验为token的的（第2位+第15位+第18位）/第2位=第31位,即第31位为3则echo flag

接下来要满足这个条件，我们需要写一个爆破脚本。

  1. hashlib是一个哈希库
  2. encode()是把字符串转换成比特流， “114514” -> b’114514
  3. hexdigest()把输出转化成十六进制字符串形式

web24

代码审计

  1. 接受get参数r
  2. mt_srand() 是 PHP 的内置函数，用于为 Mersenne Twister（梅森旋转算法） 随机数生成器设置种子。它的作用是初始化或重置随机数生成器的状态。
  3. 这里种子被固定了，所以可以提前算出来

web25

懒得截图了，直接审计吧

  1. 接受参数r
  2. mt_srand(hexdec(substr(md5($flag), 0,8)));承接上文，将md5的flag截取前八位，然后十六进制化，作为mt_srand的种子
  3. rand = r - mt_rand
  4. rand为0的时候，token为两次mt_rand随机数之和时echo flag

先传一次r试试，得到第一次echo的rand为-936176863,则第一次的随机数为936176863
